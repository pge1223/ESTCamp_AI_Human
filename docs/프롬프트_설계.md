# 프롬프트 설계

> 작성: 2026-06-08 · 담당: 동완님(프롬프트 설계) · 백엔드 연동: jyj
> 관련: [사용자_시나리오](사용자_시나리오.md), [기능정의서](기능정의서.md), [문체모델 연동 설계](문체모델_연동_설계.md)

서비스에 필요한 프롬프트 3종과, 그 **위치/소유/구현 매핑**을 정의한다.

---

## 1. 프롬프트 3종 (서비스 3단계와 매핑)

### 1-1. 세계관 프롬프트 (작가 공통) — advisory
- **단계**: 1단계 세계관 설정
- **역할**: 사용자가 폼으로 세계관/등장인물을 입력한 뒤, 작가 AI가 **대화로 보완점을 조언**한다.
  - 예: "이 캐릭터는 배경이 더 필요할 것 같아요"
  - 주연 / 조연 / 엑스트라를 나눠서 조언
  - **진입장벽을 낮추는** 역할
- **우선순위**: P1 (E2E를 막지 않음 — 폼만으로도 다음 단계 진행 가능)
- **구현**: `build_world_prompt(persona_id, world_context)`

### 1-2. 대화 프롬프트
- **단계**: 2단계 채팅 (세계관 세팅 완료 후)
- **역할**: 사용자(주인공)의 말에 맞게 작가 AI가 응답.
  - 등장인물 성격은 **세계관(폼 입력)에서 가져옴**
  - 작가 AI가 어떤 등장인물로 응답할지(또는 나레이션) 입력 보고 판단
  - (사용자 입력은 항상 주인공 고정 — [사용자_시나리오](사용자_시나리오.md))
- **우선순위**: P0 (E2E 핵심)
- **구현**: `get_author_prompt(persona_id, world_context, mode)`

### 1-3. 초안 프롬프트
- **단계**: 3단계 소설 변환 (「채팅 종료」 후)
- **역할**: 누적 대화를 소설 문체로 변환.
  - **작가 성격(문체)** 은 이 초안 작성 때 주로 반영
  - 작성 시 **큰따옴표("")** 기준으로 대사/서술 구분
- **우선순위**: P0 (E2E 핵심)
- **구현**: `NOVEL_SYSTEM` / `build_novel_system(world_description)`
  - 작가별 문체 강화(persona 주입) + 문체 모델 후처리는 [문체모델 연동 설계](문체모델_연동_설계.md) 참고 (TODO)

## 2. 위치 / 소유 규칙 (중요)

| 구분 | 위치 | 소유 |
|------|------|------|
| **런타임 프롬프트** (실제 앱이 쓰는 것) | `backend/app/core/personas.py` | 문구=동완님 / 연동=jyj |
| 프롬프트 설계(이 문서) | `docs/프롬프트_설계.md` | 동완님 |
| 학습/실험용 프롬프트 | `model/prompts/` | 동완님 |

**원칙**
- 앱이 import해서 실제로 쓰는 프롬프트는 **반드시 `backend/app/core/personas.py` 한 곳**에 둔다. (FastAPI가 import → backend 밖에 있으면 안 돌아감)
- `model/prompts/` 는 **학습/실험 전용**. 런타임에서 import하지 않는다. (과거 `system_prompts.py`가 backend를 잘못 import해 깨졌던 문제 → 제거함)
- **동완님은 `personas.py`를 직접 편집**해 문구를 튜닝한다.

## 3. 구현 매핑 (현재 코드)

| 프롬프트 | 함수/상수 | 위치 | 상태 |
|----------|-----------|------|------|
| 1-1 세계관 advisory | `build_world_prompt()` | personas.py | 🚧 초안(튜닝 필요) |
| 1-2 대화 | `get_author_prompt()` | personas.py | ✅ 동작 |
| 1-3 초안 | `NOVEL_SYSTEM` / `build_novel_system()` | personas.py | 🚧 동작(문체 강화 TODO) |

> 이전엔 초안 프롬프트가 `llm_router.py`의 `_NOVEL_SYSTEM`에, 설계 의도가 `model/prompts/system_prompts.py`(깨짐)에 흩어져 있었음 → **personas.py 한 곳으로 통합**(2026-06-08).
