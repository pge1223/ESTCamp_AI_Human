## 1. 마이페이지(내 서재) — **13탭** (데모엔 6탭만 있었음 → 전부 발굴)

좌측 메뉴: 🏠대시보드 · 🕐최근 작업 · ✨취향 프로필 · 🗂️설정집 · 💾문장 보관함 · ✏️오답노트 · 🤖AI 작가 기록 · 🎬갤러리 · 📚내 작품 · 🏆업적 · (✨말투 설정·⚙️환경설정·🔔알림설정)

### 1.1 🏠 대시보드 — 카드 7종
- ⭐🔍 **오늘의 작가 편지** — 작가가 보내는 **상황별 개인화 메시지**. 6상황 우선순위로 분기: ①첫 작품 ②1만자 달성 ③집필 완료 ④3일 미접속 ⑤슬럼프(주간 0자) ⑥기본(매일 로테이션). 작가 4인×상황별 변형 = **총 ~56종**, `{protagonist}` 자리표시자에 주인공 이름 치환.
- **나만의 말투 설정 카드** — voice 프로파일 태그(존댓말/반말·문장 길이·주요 톤2·이모지 습관) 또는 "설정하기 →".
- **이어쓰기 카드** — 최근 작품 + 진행률 바(목표 30,000자) + 상대시간("오늘 오전 10:30"/"어제"/"3일 전").
- **최근 AI 피드백 카드** — 마지막 작가 대사 80자.
- **이번 주 집필 현황** — 주간 글자/주간 목표 **10,000자** + 진행률.
- 🔍 **함께한 작가 share bar** — 작가별 협업 비율 막대(데이터 있을 때만).
- **창작 수치 5종** — 총 작품·총 글자·완결·집필 일수·작품당 평균.

### 1.2 🕐 최근 작업
- 날짜별 그룹 + "+N자" 증분 + (미완결만)**이어쓰기 →**.

### 1.3 ✨ 취향 프로필 + 🔍 취향 온보딩 모달
- **TasteOnboarding** — 책/영화/드라마 **3단계, 각 3개 선택**(총 24개 후보, 포스터+체크). 진행 인디케이터("✓ 책 → 영화 → 드라마").
- 분석 결과: **선호장르** + **선호키워드 3~5** (LLM JSON 분석).
- 후보 예: 책=나혼렙·전독시·화산귀환…, 영화=인터스텔라·기생충·듄…, 드라마=오징어게임·이상한변호사우영우….

### 1.4 🗂️ 설정집(세계관 위키) — **4 서브탭**
- **세계관** — 장르·배경·설명·규칙.
- **등장인물** — 카드(이름·역할·성격). 역할 한글화: 주인공/조연/빌런/화자.
- 🔍 **관계도** — 역할별 그룹(주인공·조연·빌런·화자) 노드 + 성격 30자.
- 🔍 **타임라인** — `story_summary`를 불릿으로 파싱한 줄거리 타임라인("대화를 이어가면 자동 생성").

### 1.5 💾 문장 보관함
- 저장 문장 카드(라벨·인용·출처 작품) + ✕ 삭제. 출처: **AI 피드백 버블의 💾 버튼**. → **취향저격 RAG의 근거**(§9.4).

### 1.6 ✏️ 오답노트
- 상위 10개 + 🔍 **정렬 2종**(가장 많이 틀린 순 / 최신순) + **count≥3 강조 테두리** + "N회" + ✕ 삭제.

### 1.7 🤖 AI 작가 기록
- 작가별 카드: 비율 바 + **함께 쓴 작품수 / 누적 대화수**.

### 1.8 🎬 갤러리 — 🔍 **리액션 영상 24종**
- 작가 4인 선택 → 감정 6종 영상: **첫 입력 반응(start)·예상 밖 전개(tension)·장면 잘 나옴(joy)·입력 없음(delays)·소설 완성(read)·로딩중(loading)**. 클릭 시 모달 재생(볼륨 localStorage).

### 1.9 📚 내 작품
- 완결작만. 카드 클릭 → 읽기(`/read/{id}`).

### 1.10 🏆 업적 — **12종**(8 기본 + 4 작가별)
| ID | 이름 | 아이콘 | 조건 |
|---|---|---|---|
| first_work | 첫 이야기 | 📖 | 작품 ≥1 |
| first_complete | 완결의 맛 | 🏆 | 완결 ≥1 |
| chars_10k | 만자 돌파 | ✍️ | 총 10,000자 |
| chars_100k | 십만자 달성 | 🌟 | 총 100,000자 |
| feedback_10 | 대화의 시작 | 💬 | 대화 ≥10 |
| feedback_100 | 백번의 대화 | 🎯 | 대화 ≥100 |
| multi_author | 다양한 시선 | 🎭 | 작가 ≥3인 협업 |
| works_5 | 다작 작가 | 📚 | 작품 ≥5 |
| author_*_3 | {작가}의 단골 | ⭐ | 해당 작가와 작품 ≥3 (백야/차로운/한여름/김도현) |
- 잠금=흑백(grayscale), 달성=풀컬러+테두리. 상단 "달성 X / Y".

### 1.11 ⚙️ 환경설정 / 🔔 알림설정
- 🔍 **배경음악**(볼륨 슬라이더 + 🔊/🔇, `bgm-volume-changed` 이벤트) · **영상 볼륨**. 알림설정="준비 중".
- 사이드바: 유저 미니 프로필(이니셜 아바타·작품수·글자수), 내 소설 목록, ← 메인.

## 2. 대화형 창작(chat)

### 2.1 입력창 버튼 4종
- ⭐ **💡 추천** — 말투 프로파일 있으면 내 말투 추천, 없으면 일반. 칩 클릭 → 입력창 삽입.
- **🔊/🔇 작가 음성 리액션 토글** — localStorage 영속.
- ⭐ **🔍 설정 검수 토글** — ON 시 `check_consistency=true`, 활성 배경 틴트.
- ⭐ **@멘션 화자 지정** — `@` → 드롭다운 → 선택 → `@이름` 칩 + placeholder "@이름의 대사 입력…". **Backspace로 화자 해제**, Esc로 드롭다운 닫기, Enter로 첫 후보 선택.

### 2.2 슬래시 명령 5종(결정론적 리액션, LLM 생략)
- `/start` `/tension` `/joy` `/delay` `/read` — 작가×감정 고정 풀에서 반응 + 감정 영상 재생.
- 🔍 **`/delay` 자동 발동** — 마지막 응답 후 **3분(180s) 무입력 시 자동**으로 "막힘" 리액션.

### 2.3 작가 AI 패널(AuthorPanel) — 🔍 태그 6종 + 토글
- **#세계관**(카드 토글) · **#등장인물**(카드 토글) · **#에피소드**(주요 에피소드 정리 요청) · **#추천**(비활성) · ⭐**#취향저격ai**(그래디언트 강조, 취향+상황+개인화RAG 추천 → "이 문장 사용하기 →") · **#도움말**(입력 문법: 대사=큰따옴표/독백=작은따옴표/행동=따옴표 없이/@멘션).
- 🔍 **작가 선택 슬라이더** — 패널에서 ‹ › 로 작가 전환(이미지·채팅·리액션 영상 동시 전환).
- 🔍 **자동 피드백 ON/OFF**(스트림 완료 2초 후 자동 피드백) · **실시간 교정 ON/OFF**(입력 시 병렬 proofread).
- 🔍 **패널 너비 드래그 리사이즈**(28vw~60vw).
- 메모 탭(🗒️ + 개수 배지), 교정 탭(✏️ + 오류 개수 배지).

### 2.4 작가 리액션(F-AS-05)
- 자막(작가 아바타 위, 마루부리 700, 15초) + 🟡 **TTS 음성 낭독**(작가별 목소리, Vercel 프록시).
- 🔍 **감정 6종**: tension·fear·sadness·joy·calm·resolve. **문맥 기반 생성**(입력+답변) → 폴백은 감정분류+고정풀. **직전 리액션 회피**(exclude).

### 2.5 메모/북마크(F-CH-11)
- 🔍 **말풍선 우클릭 컨텍스트 메뉴** → 메모/삭제. 메모=🔖책갈피 연결, 클릭 시 해당 버블로 스크롤+하이라이트. Redis 영속.

### 2.6 교정·가드·검수
- **실시간 교정 칩** + 작가 톤 메모 + "넘기기"(→ **용어집 보호어** 등록).
- ⭐🔍 **자주 놓치는 것 미리보기 카드** — "💡 자주 놓치는 것, 오늘은 미리 체크해요"(2회+ 틀린 항목, 하루 1회).
- ⭐ **장르 가드 칩** — "⚠️ 장르 밖 요소 감지" → [판타지로 도입]/[그대로 유지]. 승인 시 일방향 잠금 해제.
- ⭐ **설정 검수 모순 배너** — "🔍 설정 검수 — 모순 발견" + 설정↔충돌 + 심각도(심각/주의/경미).

### 2.7 헤더·기타
- **모드 스위처**(참여형↔집필형 토글) · 저장(최소 10초 연출) · ⭐**✎ 세계관**(수정 진입) · 목록.
- 🔍 **소설 변환 오버레이**("소설로 변환하는 중…") · 타자기 효과(TypedText) · **SSE 토큰 스트리밍**(delta/reply/audio 이벤트).
- 🔍 **스토리 단계**(도입부→전개→절정→결말, 후진 방지) — 백엔드 추적.

## 3. 세계관 생성(worldview) / 수정(worldedit)

### 3.1 생성 — 🔍 연출 풍부
- ⭐🔍 **3D 패럴랙스 아바타** — 마우스 따라 rotateY/X, **호흡 애니메이션**(4s).
- 🔍 **작가 대사 타자기 효과**(100ms/자).
- 7단계: intro→제목→요약→배경→규칙→등장인물→확인. Enter로 단계 전진.
- 🔍 **랜덤 세계관 예시**("랜덤예시" 버튼/모달) → 제목 리스트 → 상세(요약·배경·규칙·인물) → "적용"(폼 자동 채움+확인 단계 점프).
- 등장인물: +추가, 이름·성격·역할(주인공/조연)·**행동지시문**. 주인공 이름 필수.
- 🔍 **태그 자동 분류**(백엔드, §9.7) — 생성 시 장르·분위기·시대 태그 자동.

### 3.2 수정 — ⭐ soft/hard 가드
- 진입: 채팅/집필 헤더 "✎ 세계관". 힌트="다음 대화부터 바로 반영".
- 🔍 **hard 가드** — 진행 중 이야기 있으면 장르·배경에 "진행 중 변경 주의" 태그 + 경고문("지금까지 쓴 내용과 어긋날 수 있어요").
- 🔍 **기존 인물 이름·역할 잠금** — 성격·행동지시문만 보강. 새 인물은 자유 추가.
- 저장 → **서버 권위 world_context로 다음 턴 즉시 반영**.

## 5. 읽기(read) / 삽화

### 5.1 읽기 디테일
- **글자 크기**(14~20px) · **★ 북마크**(localStorage) · ⭐**↓ 내보내기(txt)** · ⭐🔍**↑ 맨 위로**(스크롤>300px 등장, 페이드인) · **상단 진행률 바**(스크롤 연동) · "{N}% 읽음".
- 좌측 **목차**(제N장, 활성 하이라이트, 단편이면 숨김) · 작품 정보(AI작가·장르·총 글자·🔍**예상 읽기 "약 N분"**·작성일).
- 표지(AI 작가 배지·제목·세계관 설명 60자·장르·단편·글자수).
- 🔍 **엔드 카드** — "— 끝 —" + "AI 작가 {name}와 함께 작성" + [이어쓰기]/[새 소설 시작].

### 5.2 삽화 — 🔍 멀티스텝 워크플로
- 우측 삽화 패널(개수 배지·빈 상태 안내) · 썸네일 → **라이트박스**(캡션·✕) · ✕ 삭제.
- 생성 모달 6스텝: **모드선택(직접 입력/AI 추천)** → 직접: 묘사 textarea → AI 추천: 🔍**4 장면 타입**(dramatic/emotional/foreshadowing/fanservice) → **StylePicker**(그림체 5·분위기 5·비율 3) → 생성 → 결과(저장/다시/닫기).
- ⭐ **Gemini로 생성**(Vertex 2.5 Flash Image) / 🟡 **OpenAI로 생성** 2버튼.
- 🔍 **안전 필터** — 부적절/저품질 입력 시 **refine(수정안 제안)** 또는 **blocked(🚫 사유 안내)** 스텝.

## 6. 메인 / 로그인

## 7. 말투 프로파일(voice) — 🔍 감정 시나리오 입력
- **필수 5문장**: 당황·서운함·미안함·거절·설렘.
- **선택 8문장**(토글로 펼침): 장난·회피·화남·진심·어색함·걱정·단호함·갈등/긴장.
- **장르 선택**(호러미스터리/추리/로맨스/일상에세이) → 🔍 장르별 감정 문장 추가.
- 자유 문장(줄 단위) + 원하는 말투 방향. 전 과정 localStorage 임시저장. 완료 화면(메인으로/수정하기).
- 비식별 고지: "분석에만 사용, 대사에 그대로 복사 안 함".

## 9. 백엔드 숨은 메커니즘(시연엔 안 보여도 발표 talking point)

### 9.1 RAG 3종
- **장기기억**: 롤링 요약(600자 예산) + 최근 8턴 제외 의미검색 top-3(Gemini 임베딩 코사인, 캐시).
- **설정 검수**: LLM 편집자(생성 아님). 같은 대상·직접 충돌만 violation, 실패 시 `consistent=True` 폴백(비차단).
- **문체 few-shot**: `style_samples.json`에서 작가별 예시 top-3 주입("베끼지 말고 목소리만"). `use_style` 토글로 A/B.

### 9.2 멀티 LLM 폴백 체인
- provider chain(groq,gemini) × 모델 스택 × 다중 키. 429→쿨다운(600s)/401→키 블랙리스트/transient→백오프 재시도. USE_VERTEX 시 ADC.

### 9.3 작가 리액션 풀
- 감정 6종 × 작가 4인 사전 작성 1줄(LLM 호출 없이 즉시). `pick_reaction(exclude=last)`.

### 9.4 취향저격 개인화 RAG
- `SavedSentence` 최근 50개 의미검색 top-k → `[사용자가 저장한 문장]` 톤 참조 주입. **통제실험 검증: DARK<NONE<WARM 단조**.

### 9.5 교정(F-QC-02)
- 네이버 맞춤법(비LLM) + 어절 단위 diff + **용어집 보호어**(고유명사 오교정 방지) + ㅋㅋ/ㅠㅠ·3연타 의도 표현 제외 + **오답노트 누적**(count, 2회+ frequent).

### 9.6 삽화 파이프라인
- 장면 추천 4타입 + 안전필터(appropriate/refine_needed/inappropriate) + Vertex Gemini Image(base64 inline, "No text/watermark").

### 9.7 세계관 태그 자동 분류
- 2단계(키워드 필터 → LLM 닫힌집합 선택), 마스터 라벨 검증. 토큰 절약.

### 9.8 화자 검증 2겹
- L1 프롬프트 규칙(장면에 실재하는 인물만 speaker, 혼자면 speaker="") + L2 멀티NPC 디스패치(맥락 적합 1인).

### 9.9 소설 변환 vs 생성 + 4축 평가
- 변환=대화→산문(작가 문체), 생성=세계관 기반. **4축 LLM-judge**: 세계관·캐릭터·문체구분도·완성도(1~5), **독립 심판(OpenAI)** 으로 자기채점 거품 제거.

### 9.10 캐싱 + TTS + phase
- Redis TTL 캐시(stream/coach/compare 3600s, "모든 작가로 비교"). TTS 작가별 voiceID·2계정 분산·첫문장 50자. phase 래칫(후진 불가).
