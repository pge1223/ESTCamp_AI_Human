# 2026-06-15 강사님 스크럼 — 냉철한 피드백 & 냉철한 자기진단

> 이 문서는 두 개의 시선을 나란히 둔다.
> **(A) 강사님의 냉철한 피드백** — 외부 심사자가 우리를 어떻게 공격할지의 예고편.
> **(B) 우리(NodeVelture)의 냉철한 시각** — 그 피드백 중 무엇을 받고, 무엇을 거를지의 판단.
>
> **핵심 한 줄:** 강사님 피드백의 80%는 *"기능을 더 만들라"가 아니라 "있는 걸 증명·가시화하라"*. 우리 진짜 리스크는 **구현 부족이 아니라 설명 부족**이다.

---

## A. 강사님의 냉철한 피드백 (원문 정리)

**1. 삽화 기능**
- 로컬에서 돌아가는 모델(Playground, 스트리밍 FLUX) 고려.
- 웹툰 수준 퀄리티는 Playground(Stable Diffusion 급).
- **무한 생성하려면 GPU 필요.**

**2. "자체 모델을 넣으려는 노력이 없다"**
- 프롬프트를 **DB에 넣고 RAG에 넣어둔** 구조를 명확히 제시할 것.
- (현재 우리: DB에서 최근 5턴 불러와 **요약**하고 관리 중 → 이 구조를 보여줘야 함.)

**3. GPT와의 차별점을 확실히 제시.**

**4. 아바타 감정 (TEXT→감정)**
- 감정이 **몇 개**인지, 어시스턴트가 **현재 문장**을 보고 판단하는지 **전체 맥락**을 보는지 명확히.

**5. 코어에 집중 — 조립을 잘 해둘 것.**

**6. (자기 점검) 개발이 산으로 가는 느낌**
- UI는 나아지는데 **기능이 뒤에서 도니까** 어떤 구조로 도는지 모르겠다.
- 음성이 아바타에 알맞게 나오는지 검증 불확실.
- → 다른 팀과 **맞검증** 고려.

**7. 코어기능 조립해서 보여드리기 — 테스트·정량 비교 필수**
- 테스트 제대로. **공격당할 가능성 큼.**
- 강사님이라면 **한쪽 GPT / 한쪽 우리 서비스**로 정량 평가.
- 다른 AI와 비교하며 **앙상블로 결과** 제시.

## B. 우리의 냉철한 시각 (받을 것 / 거를 것)

### 🟢 정확히 찌른 것 — 받아들인다

**① "어떤 구조로 도는지 모르겠다 / 산으로 가는 느낌" (피드백 6)**
가장 아픈 정답. 우리 약점은 기능이 없는 게 아니라 **기능이 뒤에서 돌아 안 보이는 것**. RAG 3종·5턴 요약·검수가 다 있는데 화면엔 "예쁜 채팅"만 보이니 외부 눈엔 껍데기로 보인다.
→ **깎는 게 아니라 "보이게" 하는 게 발표 핵심.** 기억 ON/OFF 라이브 토글, "이 대사는 검수 RAG가 12턴 전 설정과 대조했습니다" 식의 가시화.

**② "GPT와 차별점을 정량으로 증명 / 공격당할 가능성" (피드백 3·7)**
지금 차별점 서사 "RAG로 일관성"은 **GPT도 컨텍스트 길면 어느 정도 한다.** "ChatGPT에 세계관 붙여넣으면 되잖아?"라는 공격에 **수치 없으면 진다.**
무기는 이미 있다: `evidence_report`(맨손 GPT vs 우리), 기억 OFF=0점 / ON=+1.00. **있는데 안 쓰면 자살골.** GPT 채점·신뢰값 갱신까지 채운다.

**③ "자체 모델 넣으려는 노력이 없다" (피드백 2) — 절반 동의**
파인튜닝 안 한 건 의도(코어 집중)지만, 외부엔 "API 래퍼"로 보인다. 반박 카드는 **RAG 구조 그 자체** — "모델은 안 만들었지만 **검색·요약·문체 few-shot 파이프라인을 자체 설계**했다"를 **구조도 1장**으로 못 보이면 진짜 래퍼처럼 보인다.

### 🟡 반쯤 맞는 것 — 조건부 수용

**④ 아바타 감정 — 몇 개/현재 문장이냐 (피드백 4)**
질문은 정당하나 본질은 "설명이 부실하다"는 신호. 우리 답은 명확: **6종(긴장·두려움·슬픔·기쁨·평온·결심), 사용자 현재 입력 문장 closed-set 분류.**
→ 고칠 게 아니라 **슬라이드 1장으로 끝낼 일.** 단 "왜 6종? 왜 전체 맥락 안 보나?"엔 **설계 의도(실시간성·비용)**로 답할 준비.

**⑤ 음성↔아바타 검증 / 맞검증 (피드백 6)**
검증은 맞지만 **TTS는 코어가 아니라 엔터테인먼트 껍데기.** 여기 시간 쏟으면 강사님이 말한 "산으로 감"에 스스로 빠진다.
→ 데모에서 1번 보여주고 **"코어 아님"으로 선긋기.** 클라우드 IP 차단(401)은 "로컬 시연 환경 확정"으로 비용 0 처리.

### 🔴 우리 방향과 안 맞거나 과한 것 — 정중히 흘린다

**⑥ 삽화 — 로컬 모델/FLUX/GPU (피드백 1)**
따라가면 안 된다. 우리는 이미 **Vertex Gemini 2.5 Flash Image(클라우드·ADC)로 해결**, GPU 0원. 로컬 SD/FLUX는 7일 일정에 GPU 셋업으로 코어 시간을 날린다.
→ 강사님 의도(퀄리티)는 받되 수단(로컬 GPU)은 거절. **"클라우드 비전으로 동일 목적 달성"이 정답.**
+ 삽화에 피드백 분량이 많았다는 것 자체가 **데모에서 삽화를 너무 앞세웠다는 신호.** 코어(대화→소설)보다 삽화가 튀면 "껍데기 서비스"로 오해받는다.

**⑦ "앙상블로 결과 제시" (피드백 7)**
멋있지만 7일 안에 모델 앙상블은 오버엔지니어링. 강사님의 "앙상블"은 실제론 **"GPT 채점 + 우리 채점을 같이 보여 신뢰도를 높여라"** 수준의 의미.
→ **LLM-as-judge 다축 평가**로 충분. "앙상블"이란 단어에 휘둘려 코어 집중 원칙을 깨지 말 것.

## C. 일주일 행동 원칙 (흔들림 방지)

> **새 기능 < 발표용 가시화 + GPT vs 우리 정량표.**

**경계할 함정 2개**
- ⓐ 삽화 로컬 GPU 따라가기 → 시간 블랙홀.
- ⓑ TTS/음성에 코어급 시간 쓰기 → 강사님이 지적한 "산으로 감" 그 자체.

**우선순위**
1. **가시화** — RAG/검수/기억이 "돌고 있음"을 화면·데모로 드러내기.
2. **정량표** — `evidence_report`(맨손 GPT vs 우리) GPT 채점·앙상블 신뢰값 갱신.
3. **구조도 1장** — RAG 3종 + 5턴 요약 파이프라인(= "자체 설계" 반박 카드).
4. **감정 6종 흐름 1장** — closed-set 분류 설명.
5. (선택) 음성·삽화는 "코어 아님" 1회 시연으로 선긋기.
