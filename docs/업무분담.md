## 분담 기준

1. **🔥 기능 단위 책임제** — 한 기능(F-ID)은 **한 사람이 백엔드·DB·프론트·프롬프트까지 end-to-end로 담당**.
2. **코드 연속성** — 이미 그 파일·PR을 만진 사람이 그 기능을 이어서 담당
3. **전공은 배정 참고용** — 담당자를 정할 때 강점(백엔드/프론트/AI)을 참고하되, 한 기능을 여러 명이 나눠 맡지 않는다
4. **의존성 순서** — 기능 간 선후(예: 다른 기능이 쓰는 공통 API)는 순서대로, 단 한 기능 내부의 API↔화면은 담당자가 함께 처리
