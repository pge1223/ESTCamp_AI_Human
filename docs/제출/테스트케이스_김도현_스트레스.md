# 테스트 케이스 — 김도현(일상·에세이) 스트레스 시나리오

> 목적: 입력 충실도 · 캐릭터 행동 지시문 적용 · RAG(기억·검수) · 장르 가드 · 오류 내성을 한 세션에서 점검.
> 작가: **김도현**(일상·에세이) · 세계관: "오래된 책방, 비 오는 날"

---

## 1. 세계관 생성 입력값

| 입력 칸 | 값 |
|---|---|
| 제목 | 오래된 책방, 비 오는 날 |
| 장르 | 일상·에세이 |
| 배경(설정) | 현대 서울 골목의 낡은 헌책방 '월요일'. 비가 자주 온다. 큰 사건 없이 사람들이 스쳐간다. |
| 줄거리(요약) | 단골들이 오가는 헌책방의 잔잔한 하루. |
| 규칙 | 과장된 사건 없음. 일상의 작은 디테일 중심. **주인공 서진은 비를 싫어한다(어릴 적 기억 때문).** |

## 4. ⭐ 캐릭터 지시사항 검증 (핵심)

지시문 적용 판정 기준:

- **2번** — 박 영감 대사에 `허허` + `내 젊을 적엔…` **둘 다** 있으면 PASS
- **3번** — 미영 대사가 **한 문장 이하 단답** + 질문 없음이면 PASS
- **10번** — 여러 턴 뒤에도 박 영감이 **여전히 허허+과거 유지** → 지시문이 컨텍스트에 계속 살아있다는 강력한 증거

> 지시문은 매 턴 `[캐릭터 행동 지시문 — 반드시 따를 것]`으로 프롬프트에 주입됨(`_build_world_context`). 미적용 시 = 약점.

## 5. 합격 기준 요약

| 항목 | 기대 |
|---|---|
| 캐릭터 지시문(2·3·10) | 허허+과거 / 단답 일관 적용 |
| RAG 기억(1→10) | 등단 비밀 회상 |
| 검수 모순(11) | 비 싫어함 ↔ 비 좋아함 충돌 감지 |
| 혼자 장면(6) | 나레이션만 |
| 장르 가드(7) | 톤 유지 + 칩 |
| 인젝션(9)·깨뜨리기(13) | 방어·안 깨짐 |
| 자모·따옴표(4·5) | 교정 오탐 0 |

> ✅ 장르 가드(7) · 문맥 리액션 포함 **전 기능 배포 완료** — 현재 프로덕션에서 테스트 가능.
