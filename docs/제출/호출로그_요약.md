## 해석

- **주력 엔진 = Vertex AI Gemini 2.5 Flash-lite** — 전체 호출의 **86.7%**. 단가가 낮아(입력 $0.075 / 출력 $0.30 per 1M) **1콜 평균 $0.0006**의 저비용 운영.
- **폴백 체인 동작 확인** — Gemini 실패/한도 시 gpt-4o-mini·Groq llama로 자동 대체된 로그가 실제로 남음(11%+1.6%). 단일 장애점 없음.
- **prompt:completion ≈ 14.7 : 1** — 입력 토큰이 압도적. 작가 페르소나 규칙 + 세계관/캐릭터 + **RAG 검색 컨텍스트**를 매 호출에 주입하기 때문(품질↔토큰 트레이드오프). → 개선 여지: 요약·캐시로 입력 토큰 절감.
- **비용 결론** — 누적 256콜 전체가 **$0.15(약 210원)**. 데모·테스트를 충분히 돌리고도 사실상 무시 가능한 비용. 상용 확장 시에도 Flash-lite 주력 구조라 예측 가능.

> 엔드포인트별로는 `/chats/{id}/stream`(소설 응답 생성)이 호출·비용의 대부분을 차지 — 핵심 기능에 비용이 집중되는 건강한 분포.
