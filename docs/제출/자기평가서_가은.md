# 자기 평가서 — 가은 (\풀스택)

## 담당 역할
프론트엔드 (채팅 파이프라인 · 작가 AI 시스템 · 마이페이지)

## 한 일 (핵심)

**채팅 페이지 (`/chat`) 설계·구현**
- SSE 단일 응답 아키텍처 설계 (청크 스트리밍 → 완성 JSON 단발 전송, 프론트 타이핑 효과로 분리)
- narration·dialogue 분리 말풍선, `@등장인물` 태그 → 말풍선 좌우 분리
- `protagonist_dialogue` 주인공 대사 추천 이중 버블 렌더링
- 히스토리 이어쓰기 복원, 참여형↔집필형 모드 전환

**에디터 페이지 (`/editor`) 신규 구현**
- 좌측 원고 textarea (serif 폰트, 자동저장 2초 debounce, 글자 수·저장 상태 표시)
- 우측 작가 AI 패널 재사용, 자동 피드백 ON/OFF 토글 (타이핑 3초 후 최근 800자 자동 전달)
- 집필형 → 참여형 전환 시 원고 localStorage 유지

**작가 AI 시스템 (오른쪽 패널)**
- 피드백: `build_feedback_prompt` 설계 (세계관+작가 렌즈+줄거리 기반 단발성 피드백)
- 추천 문장: `build_rewrite_prompt` 설계 (원문+피드백+RAG+메모 전체 스타일 규칙 적용)
- 취향저격 AI: 취향 프로필·세계관·최근 대화·개인화 RAG 기반 3종 추천, 선택지 카드 UI

**소설 목록 페이지 (`/storylist`) 신규 구현**
- 세션 목록 조회, 이어쓰기 모드 분기 (editor / chat 자동 선택)
- 완결 작품 읽기(`/read`) 연결, 미완결 작품 이어쓰기 버튼

**AI 인물 제어**
- 다중 AI 인물 화자 오배정 근본 원인 수정: 프론트/백엔드 world_context 포맷 불일치로 `_extract_ai_char_names`가 `[]` 반환 → `_resolve_speaker` `""` 반환 → UI fallback 버그. 프론트 포맷(`등장인물:`) 파싱 추가로 해결
- 솔로 신호 오감지 수정: "아무도 없단듯이" 등 비유 표현 차단 (`_SOLO_NARR` 과거형으로 좁힘)
- 직업·역할 기반 다중 인물 화자 자동 배분 프롬프트 규칙 추가

**마이페이지 전면 개편**
- 대시보드 신설 (오늘의 작가 편지·이어쓰기·피드백·집필 현황), 상황별 편지 5종 로직
- 문장 보관함 💾 저장 버튼


## 잘한 점

- **현상이 아닌 데이터 흐름 끝까지 추적**: 화자 오배정도 "LLM이 서윤 출력 → SSE payload에 speaker 있음 → msg.speaker 비어있음 → characterName fallback" 전 구간을 추적해 포맷 불일치가 원인임을 규명
- **문제 정의 → 진단 → 해결 일관성**: Redis 다운 502, ngrok CORS, Gemini 키 형식 오류 등 모두 로그·실측으로 원인 확정 후 수정
- **방어적 설계**: AI 오응답 폴백(protagonist_dialogue → dialogue 이관), 프론트/백엔드 포맷 듀얼 지원, 솔로 신호 비유 예외 처리 등 엣지케이스를 프로덕션 이슈 이전에 설계
- 배포 함정·워크플로를 팀 전체에 공유해 시행착오 반복 방지

## 아쉬운 점

- **토큰 스트리밍 미구현**: narration·dialogue JSON 구조와 청크 스트리밍이 충돌해 단발 SSE로 타협 → 체감 TTFB를 끝까지 못 줄임
- **키워드 휴리스틱 의존**: 솔로 신호·화자 배분 등 일부를 패턴 매칭으로 처리 — NLU 기반 판단이었으면 더 견고했을 것
- **자동 테스트 부재**: 회귀 버그가 머지 후 채팅 테스트에서 발견되는 패턴 반복, 수동 e2e로 메움
