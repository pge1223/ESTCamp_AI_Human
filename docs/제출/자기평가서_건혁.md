# 자기 평가서 — 건혁 (프론트엔드)

## 담당 역할

프론트엔드 개발 · UX 설계 · 작가 인터랙션 콘텐츠 구축 · 인증 시스템 연동 · 품질 검수

## 한 일 (핵심)

### 1. 작가 콘텐츠 및 창작 진입 경험 구축

* 작가 데이터 API 및 콘텐츠 관리 구조를 구축하여 작가별 콘텐츠를 확장 가능한 형태로 설계
* 작가별 소개 영상, 테마 컬러 시스템을 구축하여 작가마다 차별화된 창작 경험 제공
* 인터뷰형 세계관 작성 시스템과 작가별 질문 세트를 구현하여 사용자가 작가와 대화하듯 세계관을 설계할 수 있도록 개선
* 작가별 예시 세계관 추천 시스템을 구축하여 초보 사용자도 손쉽게 창작을 시작할 수 있도록 지원
* 예시 세계관 자동 입력 및 적용 기능을 구현하여 세계관 작성 과정을 간소화
* 작가 선택 → 소개 → 세계관 작성으로 이어지는 사용자 흐름을 설계 및 구현

### 2. 멀티미디어 인터랙션 및 몰입감 강화

* 작가 패널 영상 시스템 구축
* 상황별 리액션 영상 24종 제작 및 적용
* 로딩 영상 및 Intro 영상 시스템 구현
* TTS 적용 및 영상 재생 흐름 개선
* 전역 영상 볼륨 관리 시스템 구축
* 작가별 BGM 시스템 및 환경설정 연동
* 페이지 이동 및 새로고침 이후에도 재생 상태가 유지되도록 개선

### 3. 인증 및 사용자 관리 기능 안정화

* Neon Auth 기반 로그인·회원가입 시스템 구축
* 사용자 인증 상태에 따른 접근 제어 구현
* Neon Auth 사용자와 서비스 DB 연동 구조 설계
* 신규 회원 DB 동기화 오류를 분석하여 이메일 검증 규칙 충돌 문제 해결
* 사용자 정보 저장 및 조회 기능 정상화

### 4. 관리자 기능 및 서비스 품질 개선

* 관리자 전용 토큰 분석 대시보드 구축
* 사용자별·기간별 토큰 사용량 조회 및 시각화 기능 구현
* 프로젝트 전 기능 검수 및 통합 테스트 수행
* 북마크 저장, Toast UI, 로딩 최적화 등 세부 UX 개선
* 서비스 출시 전 사용자 흐름 기준 예외 상황 및 오류 점검

## 잘한 점

* 단순히 기능 구현에 그치지 않고 서비스의 몰입감과 사용 경험을 개선하는 데 집중하였다.
* 영상, 음성, BGM, 테마 시스템을 하나의 사용자 경험으로 연결하여 작가와 함께 창작하는 서비스라는 콘셉트를 강화하였다.
* 인증 시스템과 사용자 데이터 연동 과정에서 발생한 문제를 원인 분석을 통해 해결하며 서비스 안정성을 높였다.
* 프로젝트 전반의 기능 검수와 통합 테스트를 수행하여 배포 전 품질 확보에 기여하였다.

## 아쉬운 점

* 인터랙션 콘텐츠와 UI 품질 향상에 많은 시간을 투자하면서 자동화 테스트 환경 구축까지는 진행하지 못했다.
* 프로젝트 기간 내에 사용자 대상 베타 테스트를 충분히 수행하지 못해 실제 사용자의 피드백을 기반으로 UX를 개선할 기회가 부족했다.
* 서비스 사용 데이터를 수집·분석하는 체계를 구축하지 못해 일부 UX 개선 사항을 정량적으로 검증하지 못했다.

## 약점 및 개선 계획

### 약점

* 주요 기능 검증이 수동 테스트 중심으로 이루어져 기능 추가 시 회귀 오류를 빠르게 확인하기 어려웠다.
* 프론트엔드와 백엔드 간 성능 지표를 실시간으로 확인할 수 있는 모니터링 체계가 부족했다.
* 사용자 행동 데이터를 기반으로 기능 개선 여부를 판단할 수 있는 분석 체계가 미흡했다.

### 개선 계획

* Playwright 기반 E2E 테스트를 도입하여 핵심 사용자 시나리오를 자동 검증할 계획이다.
* 사용자 행동 로그 및 이벤트 분석 체계를 구축하여 UX 개선을 데이터 기반으로 진행할 계획이다.

## 배운 점

* 서비스의 완성도는 단순히 기능 수보다 사용자가 체감하는 경험의 품질에 크게 좌우된다는 점을 배웠다.
* 인증 시스템, 사용자 데이터 연동, 미디어 콘텐츠 관리 과정에서 실제 서비스 운영 시 고려해야 할 안정성과 예외 처리의 중요성을 경험하였다.
* 사용자 경험 개선과 시스템 안정화는 별개의 작업이 아니라 함께 설계되어야 한다는 점을 체감하였다.
