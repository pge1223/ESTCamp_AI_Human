# AI 기반 세계관 추천 기능 도입 검토 보고서

## 1. 검토 배경

현재 프로젝트는 사용자가 소설 속 등장인물이 되어 AI와 상호작용하며 이야기를 진행하는 서비스입니다.

서비스 이용 흐름은 다음과 같습니다.

1. 작가 선택
2. 세계관 설정
3. 등장인물 설정
4. AI와 대화 및 스토리 진행

초기 기획 과정에서 사용자의 취미, 관심사 등을 입력받아 AI를 통해 맞춤형 세계관을 추천하는 기능을 검토하였습니다.

---

## 2. 문제점

### 2.1 추가 토큰 비용 발생

현재 서비스의 핵심 기능인 AI 대화 및 소설 생성 과정에서 이미 API 사용량이 발생하고 있습니다.

여기에 세계관 추천 단계까지 AI를 사용하게 될 경우,

- 세계관 생성 요청
- 추천 결과 생성
- 사용자 재생성 요청

등이 추가되어 운영 비용이 증가하게 됩니다.

특히 세계관 추천은 사용자가 여러 번 재생성할 가능성이 높아 예상보다 많은 토큰이 소모될 수 있습니다.

---

### 2.2 핵심 기능이 아님

본 서비스의 핵심 가치는 "세계관 생성"이 아니라 "등장인물과의 상호작용"에 있습니다.

사용자는 세계관을 만드는 것 자체가 목적이 아니라,

- 원하는 상황을 선택하고
- 등장인물과 대화하며
- 이야기를 체험하는 것

을 목적으로 서비스를 이용합니다.

따라서 세계관 추천은 핵심 기능이 아닌 보조 기능에 해당합니다.

---

## 3. 자료조사 결과

### 3.1 선택 과부하(Choice Overload)

UX 분야에서는 선택지가 지나치게 많아질 경우 사용자가 결정을 내리지 못하거나 서비스 이용을 포기하는 현상을 "선택 과부하"라고 합니다.

대표적으로 Iyengar & Lepper의 잼 실험에서는

- 24종류의 잼을 진열한 경우
  - 더 많은 관심을 받음
- 6종류의 잼을 진열한 경우
  - 실제 구매율이 더 높음

이라는 결과가 나타났습니다.

이는 선택지가 많다고 해서 반드시 사용자 경험이 향상되는 것은 아니라는 점을 보여줍니다.

#### 참고 자료

- 선택의 심리학: 너무 많은 옵션은 왜 사용자를 혼란스럽게 만들까?
  - https://moonee-seal.tistory.com/59

---

### 3.2 결정 피로(Decision Fatigue)

사용자는 서비스 이용 과정에서 지속적으로 선택을 해야 합니다.

본 서비스에서도

- 작가 선택
- 제목 입력
- 세계관 설정
- 등장인물 설정

등 여러 단계의 선택이 존재합니다.

여기에

- 관심사 입력
- AI 추천 생성
- 추천안 비교 및 선택

과정을 추가할 경우 사용자의 결정 피로가 증가할 가능성이 있습니다.

## 4. 대안

Ai를 활용한 세계관 추천 대신 관심사 기반 템플릿 방식을 적용했습니다.

### 예시

#### 호러 / 미스터리

- 새벽 3시의 방문자
- 안개 속의 기차역
- 거울 저편의 집
- 잊힌 학생의 교실
- 붉은 우체통
- 검은 파도
- 13번째 손님
- 달 없는 밤의 숲
- 마지막 방송
- 사라진 7일

#### 본격 추리

- 밀실의 열세 번째 열쇠
- 사라진 원고의 진실
- 폐쇄된 섬의 살인
- 시계탑의 알리바이
- 붉은 봉투의 초대장
- 살인의 수학 공식
- 무대 뒤의 범인
- 도서관의 마지막 페이지
- 유언장의 숨겨진 문장
- 완벽한 거짓 증언

#### 로맨스

- 벚꽃이 지기 전에
- 심야 서점의 연인
- 계약 연애는 처음이라
- 별빛 아래 약속
- 카페 모퉁이의 고백
- 시간을 건너온 편지
- 첫눈이 내리는 날
- 황궁의 붉은 장미
- 아이돌과 비밀 연애
- 마법사의 연애 상담소

#### 일상 / 에세이

- 오늘도 창가 자리
- 골목 끝 작은 세탁소
- 계절을 걷는 산책길
- 퇴근 후의 편의점
- 옥상 텃밭 일기
- 버스 정류장의 사람들
- 고양이와 함께 사는 법
- 비 오는 날의 독서실
- 동네 책방의 오후
- 주말 농장의 사계절

이 방식은

- 즉시 선택 가능
- 추가 토큰 비용 없음
- 빠른 서비스 진입 가능

이라는 장점을 가집니다.

## 5. 결론

현재 단계에서는 AI 기반 세계관 추천 기능보다 관심사 기반 템플릿 추천 기능이 비용 대비 효율이 높다고 판단하였습니다.

세계관 추천은 핵심 기능이 아닌 보조 기능이며, GPT를 통한 추천 기능은 추가 토큰 비용이 지속적으로 발생합니다.

또한 UX 관점에서 선택 과부하와 결정 피로를 유발할 가능성이 존재합니다.

따라서 템플릿 기반 추천 방식을 우선 적용하고, 실제 사용자 피드백과 이용 데이터를 수집한 이후 AI 추천 기능 도입 여부를 재검토하는 것이 적절하다고 판단하였습니다.
