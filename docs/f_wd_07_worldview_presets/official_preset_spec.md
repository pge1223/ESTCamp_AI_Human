## 👁️ PART 1. 호러 / 미스터리 장르 (전담 페르소나: 백야)
*   **백야 가이드라인:** 짧은 문장, 침묵의 미학, 오컬트 및 심리적 공포 유도. "공포는 안 보여주는 것이다."

### [호러 스타일 1] 오컬트 / 시골 스릴러
*   **제목:** 안개 낀 고립도 (孤立島)
*   **배경:** 지도에서 누락된 외딴섬 '낙해섬'. 장마로 여객선이 끊기고 짙은 해무가 섬을 삼켜 통신망이 차단된 고립 공간.
*   **인물:** 민우 (26, 대학생 / 유저 자아), 강 노인 (74, 갯벌에서 밤마다 피의 제사를 지내는 외눈박이 촌장).
*   **플롯:** 벽지 뒤 뱀 형상의 주술 문양 발견 -> 바깥쪽에서 잠기게 설계된 민가들의 문고리 목격 -> 자정, 촌장의 문틈 사이 경고.

### [호러 스타일 2] 심리 스릴러 / 도시 괴담
*   **제목:** 나를 보는 거울 (The Doppelgänger)
*   **배경:** 유독 층간소음이 심하고 가로등 불빛이 기괴하게 휘어져 들어오는 구도심의 낡은 빌라 302호.
*   **인물:** 수아 (24, 고시생 / 유저 자아), 거울 속 존재 (수아의 움직임보다 0.1초 늦게 움직이는 유리 너머의 형체).
*   **플롯:** 침대에 누울 때마다 느껴지는 화장대 쪽 시선 -> 거울 속 내가 좌우 반전을 잊고 나와 같은 손을 드는 오류 발견 -> 거울 속 나의 소리 없는 입모양 독백.

### [호러 스타일 3] 폐쇄 공간 / 아파트 괴담
*   **제목:** 유령동의 13층 엘리베이터
*   **배경:** 재건축을 앞두고 주민들이 이주해 텅 빈 음산한 단지 내 104동 아파트의 노후화된 엘리베이터.
*   **인물:** 준우 (29, 직장인 / 유저 자아), 노랑 패딩의 아이 (13층에서 문이 열릴 때마다 복도 끝 구석에 돌아 서 있는 아이).
*   **플롯:** 매번 아무도 없는 13층에서 열리는 문 -> 네 번째 반복 시 아이가 관절을 거꾸로 꺾으며 다가옴 -> 닫힘 버튼 먹통 후 지하로 추락.

### [호러 스타일 4] 하이테크 오컬트 / 파운드 푸티지
*   **제목:** 파일명: 고스트_캠_로그 (Ghost_Cam_Log)
*   **배경:** 의문의 집단 폐사 사건이 발생한 버려진 정신병원 지하 기도실과 야간 적외선 카메라의 초록색 화면.
*   **인물:** 도현 (27, 스트리머 / 유저 자아), 화면 속 실루엣 (육안엔 안 보이나 적외선 캠 화면 속 도현의 목을 조르는 검은 형체).
*   **플롯:** 지하 제단 앞 백색 소음 발생 -> 시청자들이 방송 화면 보라고 아우성 -> 뷰파인더 속 형체와 눈이 마주치며 질식.

## 🔎 PART 2. 본격 추리 장르 (전담 페르소나: 차로운)
*   **차로운 가이드라인:** 논리적 팩트, 까칠한 성격, 디테일 집착. "독자는 항상 작가보다 영리하다고 가정해라."

### [추리 스타일 1] 클로즈드 서클 / 밀실 살인
*   **제목:** 폭설 속의 라스트 씬 (Last Scene)
*   **배경:** 폭설과 산사태로 하산 도로와 유선 전화선이 완전히 매몰된 대관령 고딕 양식의 저택 '설화장'.
*   **인물:** 이진혁 (32, 배우 / 유저 자아), 한수현 (29, 만찬에 잠입한 관찰력이 날카로운 프리랜서 기자).
*   **플롯:** 자정 정각, 사방이 안에서 잠긴 서재에서 숨진 영화감독 발견 -> 벽난로 속 타다 남은 유언장 조각과 붉은 실크 올 확보 -> 피해자의 목구멍 깊숙한 곳에서 발견된 서재 열쇠 트릭 규명.

### [추리 스타일 2] 법의학 / 서스펜스
*   **제목:** 부패한 타임라인
*   **배경:** 한여름 한강 고수부지 풀숲에서 발견된 정체불명의 백골화 사체와 국립과학수사연구원 부검실.
*   **인물:** 원우 (31, 신입 법의관 / 유저 자아), 강 형사 (45, 강력계 베테랑 베테랑 형사).
*   **플롯:** 사망 추정 시각을 교란하는 사체 속 특이 독극물 검출 -> 피해자의 위장 내 잔류물과 용의자의 알리바이 시간대 대조 -> 부검대 위 시신이 남긴 미세한 손톱 밑 섬유 조직 분석을 통한 진범 특정.

### [추리 스타일 3] 사회파 추리 / 기업 범죄
*   **제목:** 거미줄 레이어
*   **배경:** 대한민국 최대 IT 기업 '넥스트원'의 최고층 임원실과 화려한 테헤란로 빌딩 숲의 이면.
*   **인물:** 태오 (33, 내부감사팀장 / 유저 자아), 유진 (28, 천재 화이트해커 출신 보안요원).
*   **플롯:** 핵심 개발자의 의문의 투신 자살 발생 -> 자살로 위장된 서버 로그 기록상의 인위적인 조작 흔적 발견 -> 거대 자본이 얽힌 데이터 조작과 상층부 거미줄식 지배 구조 규명.

### [추리 스타일 4] 일상 미스터리 / 코지 추리
*   **제목:** 서점 '메모리'의 도난된 페이지
*   **배경:** 골목길 구석에 자리한 조용하고 평화로운 아날로그 서점 '메모리'와 오래된 책 냄새가 나는 공간.
*   **인물:** 민재 (25, 서점 아르바이트생 / 유저 자아), 혜수 (27, 매일 같은 시간 단골 단골 손님).
*   **플롯:** 매주 화요일마다 특정 초판본 서적의 특정 페이지만 칼로 오려져 나가는 사건 발생 -> 현장에 남겨진 북마크와 연필 가루 단서 추적 -> 도난된 페이지의 문장들이 가리키는 20년 전 서점 소유주와 얽힌 비밀 규명.

## 💘 PART 3. 현대 로맨스 장르 (전담 페르소나: 한여름)
*   **한여름 가이드라인:** 감각적이고 섬세한 묘사, 풍부한 감정선. "심장이 두근거려야 페이지를 넘긴다."

### [로맨스 스타일 1] 일상 / 잔잔한 힐링
*   **제목:** 비가 내리는 카페, 0.5초의 간격
*   **배경:** 오래된 기와와 돌담길이 매력적인 서울 서촌의 아날로그 레트로 북카페 '소나기'.
*   **인물:** 지호 (28, 슬럼프에 빠진 공간 디자이너 / 유저 자아), 연우 (26, 폭우를 피해 처마 밑으로 들어온 플로리스트).
*   **플롯:** 처마 밑에서 떨고 있는 연우에게 따뜻한 라떼와 수건 건넴 -> 카페 안 테이블에서 부서진 꿈에 대해 나누는 교감 -> 비가 개고 문을 나서려는 연우의 손목을 잡는 클라이맥스.

### [로맨스 스타일 2] 오피스 / 혐관 로맨스
*   **제목:** 계약 조건: 프로젝트 마감 30일 전
*   **배경:** 업계 1위 광고 대행사 메인 회의실과 24시간 불이 꺼지지 않는 치열한 디자인 기획실.
*   **인물:** 현우 (30, 까칠하고 완벽주의인 아트디렉터 / 유저 자아), 서아 (28, 통통 튀는 성격의 카피라이터).
*   **플롯:** 미팅마다 사사건건 부딪히며 앙숙으로 소문난 두 사람 -> 대기업 메인 프로젝트 총괄로 공동 묶이며 강제 밤샘 근무 시작 -> 밤샘 기획 중 발견한 서로의 이면과 마감 직전 탕비실에서의 묘한 텐션.

### [로맨스 스타일 3] 학원 / 청춘물
*   **제목:** 유월의 주파수
*   **배경:** 푸른 싱그러움이 가득한 한여름의 고등학교 방송실과 노을빛이 드는 운동장 조화.
*   **인물:** 시우 (18, 방송부 엔지니어 / 유저 자아), 하은 (18, 학교 축제 메인 아나운서).
*   **플롯:** 축제 오디션을 앞두고 발음이 꼬여 방송실에서 혼자 울고 있는 하은 발견 -> 마이크 볼륨을 조절해 주며 오직 둘만의 주파수로 스피치 코칭 -> 마이크가 켜진 줄 모른 상태에서 고백이 전교에 송출될 뻔한 위기.

### [로맨스 스타일 4] 판타지 / 타임슬립
*   **제목:** 다시 만난 계절의 끝에서
*   **배경:** 벚꽃이 흩날리는 캠퍼스 교정과 10년의 시간을 주기로 과거와 현재를 연결하는 오래된 공중전화부스.
*   **인물:** 도진 (28, 서른을 앞둔 건축가 / 유저 자아), 미래 (20, 10년 전 대학정문에서 홀연히 사라진 첫사랑).
*   **플롯:** 첫사랑이 사라진 날과 동일한 날짜에 공중전화가 울림 -> 10년 전 과거의 그녀와 통화가 연결되는 초현실적 현상 -> 과거의 사고를 막아 그녀의 운명을 바꾸고 현재의 교정에서 재회하는 기적.

## ☕ PART 4. 일상 / 에세이 장르 (전담 페르소나: 김도현)
*   **김도현 가이드라인:** 담담한 어조, 사색적 접근, 평범함의 문학화. "특별한 하루보다 평범한 순간이 문학적이다."

### [에세이 스타일 1] 현대인 위로 / 자아 성찰
*   **제목:** 무너진 자정, 온전한 나를 마주하는 시간
*   **배경:** 낮 동안의 치열함을 벗어나 오롯이 혼자가 된 밤 11시 45분의 은은한 노란 스탠드가 켜진 7평 원룸 방.
*   **인물:** 서현 (29, 광고 대행사 5년 차 직장인 / 유저 자아), 내면의 나 (거울 속에서 위로를 건네는 따뜻한 자아).
*   **플롯:** 일기 첫 줄에 '오늘도 거짓말을 했다' 적기 -> 상사의 모욕과 삼켜야 했던 감정의 파편 고백 -> 만원 버스 속 한강 야경을 복기하며 평범한 삶이 주는 담담한 치유와 새벽의 다짐.

### [에세이 스타일 2] 여행 / 방랑의 기록
*   **제목:** 완행열차와 낡은 노트
*   **배경:** 목적지 없이 무작정 몸을 실은 남행 완행열차의 차창 밖 풍경과 빛바랜 간이역들의 연속.
*   **인물:** 동민 (32, 퇴사 후 배낭을 멘 방랑자 / 유저 자아), 노승무원 (30년간 기차를 지켜온 노인).
*   **플롯:** 속도 지상주의 도시를 떠나 느리게 흘러가는 열차 안 창가석 안착 -> 간이역에 내리는 사람들의 소박한 표정과 짐가방 사색 -> 노승무원이 건넨 따뜻한 캔커피 한 잔에서 발견한 멈춤의 가치 기록.

### [에세이 스타일 3] 가족 / 기억의 잔상
*   **제목:** 할머니의 손때 묻은 반섓고리
*   **배경:** 시골집 안방의 장롱 깊은 곳에 보관되어 있던, 세월의 흔적이 가득한 오래된 목조 반섓고리 상자.
*   **인물:** 수민 (27, 도시 생활에 지친 손녀 / 유저 자아), 할머니의 기억 (반섓고리 속 물건들에 남아있는 온기).
*   **플롯:** 명절을 맞아 내려간 시골집에서 우연히 상자를 열어봄 -> 삐뚤빼뚤한 바느질 자국이 남은 어린 시절의 베개 가루 발견 -> 투박하지만 조건 없는 사랑으로 나를 키워낸 할머니의 거친 손등과 따뜻한 밥상을 추억하며 내면 회복.

### [에세이 스타일 4] 음식 / 소소한 일상
*   **제목:** 보글거리는 된장찌개와 1인분의 온도
*   **배경:** 노을이 지는 저녁 시간, 도마 위 야채 써는 서툰 칼질 소리가 울리는 조용한 1인 가구의 주방.
*   **인물:** 재희 (28, 자취 3년 차 사회초년생 / 유저 자아), 요리의 시간 (오롯이 나만을 위해 정성을 들이는 치유의 순간).
*   **플롯:** 유독 차가웠던 하루를 마치고 오직 나를 대접하기 위해 가스레인지 불을 켬 -> 보글거리는 된장찌개 냄새가 좁은 방안을 온기로 가득 채움 -> 거창한 배달 음식 대신 투박한 1인분의 식탁을 차리며, 나를 사랑하는 법을 배우는 저녁의 기록.
