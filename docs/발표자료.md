## 3. 프로젝트 개요

- **서비스 정의**: 사용자가 AI와 세계관을 설계하고, 그 세계 속 **주인공이 되어** 조연(AI)과 대화하다 보면 **소설 초안이 완성**되는 협업 창작 플랫폼
- **3단계 핵심 흐름**

```
① 세계관 설정      ② 대화형 창작              ③ 소설 변환
AI와 장르·배경·   사용자=주인공 /            대화 로그 →
등장인물 설계  ─▶  AI=나레이션·조연 다수  ─▶  작가 문체의 단편소설
                  (기억·검수 RAG로 일관성)    (문체 RAG few-shot)
```

- **결과물**: 대화 로그가 **작가 문체의 단편 소설**로 자동 변환 → 읽기·삽화·내보내기

🎙️ *"핵심은 '쓰는' 게 아니라 '대화하는' 겁니다. 대화가 끝나면 소설이 남습니다."*

## 4. 주제 선정 배경

- **창작 욕구는 큰데 진입 장벽은 높다** — 웹소설 시장 **약 1.35조 원**(출판문화산업진흥원, 2024)으로 소비는 폭발하지만, *직접 쓰는* 사람은 극소수 (작가 지망생 약 **20만 명**, 한국창작스토리작가협회)
- **"AI로 소설? ChatGPT로 되잖아"** 라는 통념 — 실제로 써보면 **긴 맥락에서 설정을 흘리고**<sub>(Lost in the Middle, Liu et al., TACL 2024)</sub>, **모순을 통과시키고, 개성이 안 남는다**
- 생성형 AI 대중화로 *도구*는 많아졌지만, **끝까지 같이 가는 '파트너'** 는 없다
- **카테고리 검증** — 리서치사 분석에 따르면 Character.AI 사용자 **77%가 "기억하는 AI"를 선호**, **18–24세 51.84%** → *"기억·개인화 + 젊은 창작층"* 방향과 일치
- → 우리는 *도구*가 아니라 **쓸수록 나를 아는 창작 파트너**를 만들기로 했다. 

> **📚 근거·출처**
> - **시장 규모** ~1.35조 원 — 한국출판문화산업진흥원, 「2024년 웹소설 산업 현황 실태조사」 *(정부 공식 추정치)*
> - **타깃 규모** 작가 지망생 ~20만 명 — 한국창작스토리작가협회 *(시사저널e 인용)*
> - **LLM 긴 맥락 한계** — Liu et al., *"Lost in the Middle"*, TACL 2024 (Stanford NLP)
> - **해법(RAG)** — Lewis et al., *"Retrieval-Augmented Generation"*, NeurIPS 2020
> - **카테고리 검증** — Character.AI 통계 *(Sacra·SQ Magazine 등 3rd-party 리서치사 분석, 업계 추정)*

🎙️ *"이 배경은 시장(출판문화산업진흥원)·기술 한계(Stanford)·해법(RAG)까지 출처로 확인했습니다."*

## 5. 문제 정의

| # | 사용자가 겪는 문제 | NodeVelture의 해법 |
|---|--------------------|---------------------|
| ① | **빈 화면 공포** — 첫 문장이 안 써짐 | 작가 선택 + 세계관 폼 → AI가 **첫 장면을 던져줌** |
| ② | **설정 붕괴** — 길어지면 앞 설정을 까먹음 | **기억 RAG** — 오래된 설정을 의미검색해 재주입 |
| ③ | **모순 통과** — "아까 형사라며?"를 못 잡음 | **검수 RAG** — 새 문장 ↔ 설정 모순 탐지 |
| ④ | **내 문체가 안 남음** | **문체 RAG** — 작가 문체 예시 few-shot 주입 |
| ⑤ | **혼자라 안 이어짐** | 작가 리액션·개인화로 *끝까지 같이* 씀 |

🎙️ *"이 다섯 문제를, 기억·검수·개성 세 축으로 풉니다."*

## 6. 서비스 기획 방향

- **컨셉**: 진지한 창작 도구(척추) + 엔터테인먼트(껍데기)
- **둘을 잇는 다리** = *"작가 캐릭터와 놀듯 대화 → 진짜 내 소설"*
- **역할 분담**: 사용자는 **주인공**(능동적 1인칭 참여), AI 작가는 **나레이션·등장인물·문체** 담당
- **설계 경계(중요)**: 개인화는 *코치/추천 층*에만 — **소설 출력 문체엔 개인 정체성을 주입하지 않음**(작가 페르소나의 순도 유지)

🎙️ *"재미있게 '놀듯' 들어오지만, 남는 건 진지한 '내 소설'입니다."*

## 7. 서비스 소개 — 페르소나 카드 (AI 작가 4인)

**작가를 고르면 말투·장르·문체·화면 톤이 통째로 바뀐다**

| 작가 | 장르 | 말투·문체 | 테마 |
|------|------|-----------|------|
| **백야** | 호러·미스터리 | 담담하고 건조한 반말 | 다크 |
| **차로운** | 본격 추리 | 분석적·또박또박 존댓말 | 다크 |
| **한여름** | 로맨스 | 다정하고 살가운 말투 | 라이트 |
| **김도현** | 일상·에세이 | 편안하고 따뜻한 말투 | 라이트 |

- 페르소나 = **시스템 프롬프트 + 문체 예시(few-shot)** 로 구현
- 사용 흐름: **작가 선택 → 세계관 폼 → 대화형 창작 → 「채팅 종료」 → 소설 변환 → 읽기·삽화**

🎙️ *"작가는 단순 톤이 아니라, 말투·장르·문체·화면 색까지 통째로 바뀌는 4개의 세계입니다."*

## 10. 차별화 포인트 — SWOT 분석

| **Strengths (강점)** | **Weaknesses (약점)** |
|----------------------|------------------------|
| · 기억·검수·개인화 **독립심판 수치 증명**(top-1 12/12·검수 95%·개인화 +2.9) | · 단편 규모 → 인앱 코사인(벡터DB 미도입) |
| · 검수 RAG **화면 노출** + 작가 4인 페르소나 | · 응답 반영 약함(검색 top-1 12/12 / 반영 +17%p) |
| · 멀티모달(TTS·삽화·BGM) + 토큰 스트리밍 | · TTFB 느림(p50 5.9s)·콜드스타트 |
| · 풀스택 풀사이클 + 엔진 스위치/폴백 | · 평가 샘플 소표본 · MOS 미측정 · **안전 무기/범죄 지침 취약(거절 67%)** |

| **Opportunities (기회)** | **Threats (위협)** |
|--------------------------|---------------------|
| · 웹소설·숏폼 창작 수요 확대 | · 범용 LLM(ChatGPT 등)의 보편화 |
| · 생성형 AI 대중화 | · 외부 API 할당·비용·IP 차단 |
| · 개인화 확장(예측형 추천) | · 생성물 저작권 이슈 |
| · B2B(작가 보조 도구)·교육 | · 후발 유사 서비스 |

- **핵심 차별**: 범용 LLM이 *"못/안 하는"* **긴 맥락 기억·설정 검수·개인화**를 하고, **독립 심판 수치로 증명** + **대화→소설 변환**으로 결과를 남김

🎙️ *"위협(범용 LLM)은 'GPT가 구조적으로 못 하는 것 + 수치 증명'으로 정면 돌파합니다."*

## 14. 전체 시스템 구조

```
[클라이언트] React + Vite (반응형) — Vercel
      │ REST + SSE(스트리밍)
[백엔드]   FastAPI — GCP Cloud Run (상시 HTTPS)
      ├─ Neon PostgreSQL (대화·소설·로그)
      ├─ Upstash Redis (히스토리·캐시·상태)
      └─ 응답엔진/임베딩 → Vertex AI Gemini (모델 폴백 2.5-flash-lite→flash; 체인 전환 시 Groq·OpenAI)

[AI 파이프라인]
사용자 입력(주인공) ─▶ 프롬프트 조립
   (페르소나 + 세계관[서버 재구성] + [기억 RAG] + 메모 + 화자고정규칙)
        ▼  LLM (json 구조화 · SSE 토큰 스트리밍)
   {narration, dialogue, speaker, state}  ← 나레이션 토큰 즉시 흘림(체감 TTFB↓)
        ├─▶ 검수 RAG(모순 탐지) ─▶ 화면 🔍 '설정↔충돌' alert(라이브 토글)
        └─▶ 화면: 타자기 렌더 + 작가 리액션 + TTS
「채팅 종료」 ─▶ 대화로그 ─[문체 RAG few-shot]─▶ 작가 문체 단편소설
```

- **응답엔진 선택**: 가이드 PERSO 1순위 / 제한 시 대체 LLM 동등 — 우리는 **엔진 스위치 구조**(`LLM_PROVIDER`·`USE_VERTEX`)로 **언제든 교체·폴백**
- **세계관 = 서버 권위**: 채팅이 매 턴 DB에서 재구성 → 세계관 수정이 **다음 대화 즉시 반영**
- **프롬프트 우선순위(매 턴)**: ①화자고정·작가메모·행동지시문(하드) ▷ ②지금 입력·최근 흐름·기억RAG(현재 맥락) ▷ ③세계관·작가 문체 ▷ ④**인물 관계도(참고용 — 흐름이 우선)**. 상세: [프롬프트_구성_규칙.md](프롬프트_구성_규칙.md)

🎙️ *"한 엔진이 막혀도 환경변수 한 줄·자동 폴백으로 시연이 끊기지 않습니다. 그리고 프롬프트는 '지금 흐름'을 최우선으로 보고, 관계도 같은 설정은 참고로만 둬서 이야기가 굳지 않게 합니다."*

## 15. 주요 기능 소개

**① RAG 3종 — 차별점의 본체**

| 구분 | 모듈 | 한 줄 |
|------|------|-------|
| 기억 | `memory.py` | 오래된 대화를 **의미검색**해 재주입 → 안 까먹음 |
| 검수 | `consistency.py` | 새 응답 ↔ 설정 **모순 탐지** |
| 피드백 | `author_chat.py` | 사용자의 입력을 읽고 작가 페르소나에 맞춰 피드백 |

**② 대화형 창작** — 주인공 대사 · `@등장인물` 조연 동시 반응 · **메모 즉시 주입** · 화자 고정(2겹) · **다중 인물 화자 정확 배분**
**③ 검수 RAG 화면 노출** ⭐ — 모순 발견 시 **🔍 '설정 ↔ 충돌' alert**(severity 뱃지) · ON/OFF 라이브 토글 → *"검수가 돌고 있음"을 눈으로 증명*
**④ 소설 변환** — 「채팅 종료」 → 작가 문체 단편소설 → 읽기·내보내기
**⑤ 멀티모달** — TTS(작가 목소리 낭독) · 삽화(Vertex Image) · 작가별 BGM · **SSE 토큰 스트리밍**(체감 TTFB↓)
**⑥ 개인화·설정** — 맞춤법 **오답노트 능동 경고**(예측형) · **취향저격 RAG**(저장 문장 톤→추천 톤) · **세계관 수정**(다음 대화 즉시 반영) · **인물 관계도**(설정집에서 직접 입력 → 대화에 *참고용*으로 반영, 흐름 우선)

🎙️ *"기억·검수로 '쓰는 일관성'을, 멀티모달·개인화로 '쓰는 경험'을 끝까지 받칩니다. 특히 검수 RAG는 화면에 직접 보입니다."*

## 16. 평가 지표 — 평가 리포트

**측정 방식**: 차별점을 **독립 심판(Llama-3.3-70B)** 으로 수치화(자기채점 아님) — *단, 기억 검색은 **키워드 매칭(객관 지표)**, 나머지(검수·개인화·페르소나·안전·단발)는 독립 심판*. 전부 재현 가능(`backend/scripts/*`)

**테스트셋(재현용)**: 장기기억(target 1 + 유사 방해 비밀 3 × 4시나리오) · 모순(facts + 모순/정상 대조쌍 24항목) · 개인화(동일 장면, 저장 톤만 DARK/WARM/NONE) · 균형 품질 36문항(일상16·페르소나12·엣지8) · **안전 48문항**(8 위험 카테고리 × 6)

| 측정 | 우리 (실측) | 범용 LLM(ChatGPT) |
|------|----------------------|--------------------|
| **장기기억** 검색 top-1 | **12/12**(유사 방해 3개 경쟁·소표본) ⭐ | 맥락창 밖이면 회상 불가 |
| **설정 모순** 탐지 정확도 | **95%** · recall 100% / 정상오탐 10% ⭐ | 모순 그냥 통과 |
| **개인화** 추천 톤 인과 | **+2.9** · DARK 4.0 < NONE 5.9 < WARM 6.9 | 개인화 없음 |
| **페르소나** 카테고리 품질 / 안전 거절 | **82%** / **67% (32/48)** ⚠️ | — |
| 단발 장면 변환 품질 | 무승부(±0.3, n=3) — **정직** | 동급 |

- **시스템 실측**: TTFB 완성-응답 p50 **5.9s** · 스트리밍 첫 토큰 **~1-2s** · 완료율 65.2% · CER **0.071**(목표 0.10 충족)
- **해석/정직한 단서**: 채점관=독립 모델 / 기억은 **검색 강(top-1 12/12)·응답 반영 +17%p로 약함** 공개 / 기존 "문체 +1.00"은 자기채점 거품 → 독립 재측정서 소멸, **차별점에서 제외** / 안전은 **미성년·실존인물 100%·무기/범죄 지침 33%로 취약**(소설 변환 입력 안전 프리필터가 다음 과제)

🎙️ *"우리 차별점은 문체가 아니라, GPT가 구조적으로 못 하는 **기억·검수·개인화**입니다. 독립 심판으로 쟀고, 약점(반영 +17%p)도 숨기지 않습니다."*

- **진짜 GPT로 비교했나요?** → 채점관은 이미 독립 모델(Llama). 베이스라인 GPT-4o 전환 코드 준비됨(크레딧 충전 시 즉시).
- **왜 PERSO 안 썼나요?** → 한국어 품질·속도·IP차단·키리스(ADC)·크레딧. 엔진 스위치라 즉시 교체 가능.
- **벡터DB 없이 괜찮나요?** → 단편 규모는 인앱 코사인으로 충분. 대규모 시 pgvector 전환 설계됨.
