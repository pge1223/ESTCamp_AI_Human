## Phase 1 — 초기 모델 구축

### 사전 준비 작업

- 금감원 데이터(MP4) → Whisper STT → 텍스트 변환
- 금감원 텍스트 GPT-4o-mini 증강 (100 → 500건)
- AI Hub 윤리 검증 데이터셋 추가
- 4가지 클래스 라벨링 (기관사칭 / 금전요구 / 개인정보 / 정상)
  - 클래스 세분화 논의 → 멀티라벨 방식으로 전환 결정

### 작업 단계

| 단계 | 내용 | 상태 |
|------|------|------|
| 데이터 수집 | 금감원 MP4 104개 | ✅ 완료 |
| STT 전처리 | Whisper small → 텍스트 변환 | ✅ 완료 |
| 데이터 증강 | GPT-4o-mini 359개 생성 | ✅ 완료 |
| 라벨링 | 키워드 빈도 기반 자동 라벨링 | ✅ 완료 |
| 멀티라벨 변환 | 복합 제거 → [기관사칭, 금전요구, 개인정보] | ✅ 완료 |
| 데이터 분할 | train 451 / val 56 / test 57 | ✅ 완료 |
| 파인튜닝 | KoELECTRA 멀티라벨 학습 | ✅ 완료 |
| ONNX 변환 | PyTorch → ONNX | ✅ 완료 |
| TFLite 변환 | ONNX → TFLite float32 (430MB) | ✅ 완료 |
| TFLite 추론 검증 | 테스트 문장 10개 추론 확인 | ✅ 완료 |

### 성능 평가 (v1)

**데이터셋**: `test_ml.json` — 57개 (피싱 41 / 정상 16)  
**라벨 분포**: 기관사칭 19 / 금전요구 17 / 개인정보 17

#### 방법 비교

| 단계 | Accuracy | Precision | Recall | F1 (이진) | F1 (macro) |
|------|--------:|----------:|-------:|----------:|-----------:|
| ① 키워드 규칙 기반 | 93% | 97% | 93% | 95% | 85% |
| ② KoELECTRA 베이스 (파인튜닝 전) | 72% | 72% | 100% | 84% | 27% |
| ③ KoELECTRA 파인튜닝 (v1) | **100%** | **100%** | **100%** | **100%** | **95%** |

#### 파인튜닝 모델 카테고리별 F1

| 기관사칭 | 금전요구 | 개인정보 |
|---------:|---------:|---------:|
| 93% | 95% | 97% |

#### 핵심 해석

- **① → ③**: 파인튜닝 모델이 키워드 규칙 대비 F1(bin) +5%p, F1(macro) +10%p 향상. 키워드 없이 문맥만으로 보이스피싱을 판단하는 능력이 추가됨.
- **② → ③**: 동일한 KoELECTRA 아키텍처라도 파인튜닝 없이는 F1(macro) 27%에 불과. 도메인 특화 학습이 필수임을 입증.
- **①이 ②보다 높은 이유**: 베이스 모델의 분류 헤드가 랜덤 초기화 상태라 대부분의 입력을 피싱으로 예측하는 편향 발생 (Recall=100%지만 정상 오탐 多).

### 문제점 발견

데이터 양이 적어 제대로 된 분류가 안 되는 케이스 확인.  
아래 10개 테스트 문장 중 정상 2개를 모두 피싱(`기관사칭`)으로 오분류.

```

판정: 기관사칭  | 서울중앙지검입니다. 귀하 명의로 대포통장이 개설되어 긴급 소환장이 발부되...
판정: 금전요구  | 지금 바로 안전계좌로 3천만원을 이체하지 않으면 자산이 동결됩니다....
판정: 금전요구  | 공탁금 500만원을 오늘 중으로 입금하셔야 사건이 종결됩니다....
판정: 개인정보  | 본인 확인을 위해 주민등록번호 뒷자리와 OTP 번호를 말씀해 주세요....
판정: 기관사칭  | 통장을 저희 직원에게 양도해주시면 조사 후 돌려드리겠습니다....
판정: 금전요구  | 저는 서울중앙지검 수사관입니다. 안전계좌로 즉시 송금해 주세요....
판정: 개인정보  | 경찰청입니다. 귀하 명의 계좌가 범죄에 사용됐으니 주민번호와 카드번호를 ...
```

### 공통 오탐 패턴

| 패턴 | 오인 카테고리 | 원인 |
|------|-------------|------|
| 뉴스/보도 텍스트 (고소, 검찰, 사건 등) | 기관사칭 | 법률 용어 과적합 |

### 개선 방향

1. **뉴스/보도 도메인 정상 샘플** → 일반 전화 맥락과 다르다고 판단하여 보류
2. **콜센터 환불 맥락 구분 강화** → 콜센터 데이터 약 2,500개 추가 학습 예정
3. **FP 7건 동일 반복** → 해당 샘플을 train에 즉시 추가하는 것은 의미 없다고 판단, 일반 대화 데이터셋 약 10,000개 보강 예정
4. **키워드 필터 미통과** → 키워드 보강 예정. 임시 조치로 임계값을 낮춰 키워드 필터를 모두 통과하도록 변경
