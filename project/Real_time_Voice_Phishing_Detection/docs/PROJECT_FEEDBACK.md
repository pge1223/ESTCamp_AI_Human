## 강사 피드백

- **데모 부족** — 실제 동작을 보여주는 시연이 충분하지 않았음
- **내용 과다** — 내용이 너무 많아 본질적인 메시지가 가려짐
- **발표 방식** — 마우스 포인터로 화면을 짚어가며 설명했으면 더 효과적이었을 것
- **자료 구성** — 슬라이드는 심플하게, 영상은 풍부하게 (영상에 대한 자세한 구두 설명 필요)
- **데이터 분할** — 일반적으로 val 20% / train 10% 비율 권장

## 학습튜터 피드백

### 잘한 점

- **문제 정의** — *"통화가 진행되는 시간 안에 아무도 피해자 곁에 없다"* 는 한 문장이 발표 전체를 관통하는 강력한 핵심이었음
- **모델 구현** — 이번 프로젝트 최고 수준으로 평가
  - RawNet2 설계
  - 5단계 반복 데이터 고도화
  - 코덱 / 재녹음 / MP3 압축 시뮬레이션으로 실전 환경 체계적 검증
  - **EER 1.03% 달성**
  - 데이터 리키지 방지를 위한 464명 화자 격리 → 모델 신뢰도 향상

### 보완할 점

- **시연 영상 음량** — 음성 AI 프로젝트임에도 시연 영상 소리가 작아 핵심 결과물을 충분히 전달하지 못함
- **케이스 영상 부족** — "실제로 어떻게 작동하는가"에 대한 청중의 궁금증을 충족시키지 못함. 다양한 시나리오 테스트 결과를 공유했으면 좋았을 것
- **페르소나 구체성** — 페르소나가 통계 수준에 머문 점이 아쉬움. 구체적 인물 설정이 있었다면 기술적 완성도와 시너지가 컸을 것

### 튜터 코멘트

> 모델 설계-개선 사이클의 완성도는 1차 프로젝트 수준을 넘어섬.
> 다음 프로젝트에서는 **"만든 것을 어떻게 보여주는가"** 에 같은 수준의 공을 들이길 권장함.
